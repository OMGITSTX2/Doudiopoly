# Doudiopoly

A modern, responsive 2D property-trading board game inspired by classic British board games.

## Current features

- Responsive desktop and mobile interface
- Local rooms with shareable room codes
- Practice players
- Manual dice movement and end-turn controls
- Player tokens and coloured ownership markers
- Property purchasing, trading, mortgages, rent, and bankruptcy
- Doudi Free Parking mechanic
- Human-readable `.txt` save and load support

## Run locally

Open `index.html` in a browser, or serve this folder with any local static web server.

This project currently uses plain HTML, CSS, and JavaScript. Online multiplayer backend support is planned for a later stage.
